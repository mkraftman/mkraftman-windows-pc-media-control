# Mkraftman Windows PC Media Control

Custom Lovelace card for Home Assistant providing transport controls for a Windows PC via Unified Remote.

Matches the visual style of the Sky Q media control card with the Windows image as background.

## Features
- Home button (navigates to streaming dashboard)
- Rewind / Play-Pause / Fast-forward (via Unified Remote media keys)
- Windows key button

## Installation
Install via HACS as a custom repository.

## Requirements
- [hass-unified-remote](https://github.com/akshansh1998/hass-unified-remote) integration
- Unified Remote Server running on target Windows PC
